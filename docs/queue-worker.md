# تشغيل عامل الطوابير (Queue Worker)

توليد محتوى المنتجات (فردي بعد الإنشاء أو جماعي من صفحة المنتجات) يعمل عبر **Laravel Queue** حتى لا يتجمّد خادم الويب.

## المتطلبات

في ملف `.env`:

```env
QUEUE_CONNECTION=database
```

تأكد من وجود جداول `jobs` و`job_batches` (تُنشأ عبر migrations الافتراضية).

## تشغيل العامل

في **طرفية منفصلة** عن `php artisan serve`:

```bash
php artisan queue:work --queue=default --sleep=3 --tries=2
```

للإنتاج، استخدم Supervisor أو systemd لإبقاء الأمر يعمل بعد إعادة التشغيل.

## ماذا يحدث بدون عامل؟

- لوحة التحكم والمتجر **يعملان بشكل طبيعي**.
- طلبات التوليد تُخزَّن في جدول `jobs` وتنتظر التنفيذ.
- زر «توليد محتوى جميع المنتجات» يبدأ الدفعة فوراً دون تجميد الصفحة؛ التقدم يظهر عندما يبدأ العامل المعالجة.

## التحقق

```bash
php artisan queue:failed
php artisan queue:retry all
```
